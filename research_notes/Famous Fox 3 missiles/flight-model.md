# Active-radar air-to-air flight, guidance, and seeker handover

Scope is the flight of the class: launch, midcourse, loft, datalink, seeker handover, motor state, and the terminal law this sim already adopted. It is not a missile-by-missile catalog, and it does not re-derive the monostatic range equation. Detection, clutter, and glint stay in `reports/Sensor weapon and terrain physics.md`. The existing point-mass step is Y-up, metres, 0.01 s (`Application.h` `m_timeStep`), with thrust plus a nozzle pressure term and drag from dynamic pressure (`Fox2Flight.h`). DTIC HTML landing pages returned a maintenance page on 2026-09-29, so two reports that search indexes still quote (ADA386524 handover baskets, ADP005719 ducted-rocket speed control) were not re-opened and are not cited.

## Phase sequence from launch through coast

### Takeaway

An active-radar round is not one guidance law with a range gate. Open sources split the flight into a launcher-clearance interval, an inertial midcourse fed by pre-launch state and optional updates, a seeker search of the handover basket, and terminal homing only after acquisition. Motor coast is a propulsion state, not a guidance mode. No opened text gives a single switch that is “the” active-seeker range.

### Cited Findings

- Homing perceives the target on the missile, extracts track data, and computes its own steering commands. Active homing is a self-contained radar: the missile transmits and tracks the reflection. Semi-active uses an external illuminator. Passive uses energy that originates at the target, including jamming. A fixed angular error at the missile becomes a smaller linear error as range falls. — [Skolnik, *Radar Handbook*, ch. 19](https://ww.helitavia.com/skolnik/Skolnik_chapter_19.pdf)
- Active range is considerably less than a comparable semi-active seeker with a high-power, large-antenna illuminator, because of missile antenna size and transmitter power. Active all-the-way is therefore a short-range mode. The long-range pattern is a midcourse mode (inertial or command) that brings the missile inside terminal range, “typically the last 10 guidance time constants or a few kilometers from intercept.” Pre-launch data or in-flight command updates initialize seeker angle and range and/or Doppler. The seeker searches the target uncertainty, and only after acquisition does terminal homing start. The same chapter later says later-generation homing lasts “only the last few seconds of flight (typically 10 guidance time constants),” and that an inertial or commanded up-and-over trajectory spends less time in dense low-altitude air. — [Skolnik, ch. 19](https://ww.helitavia.com/skolnik/Skolnik_chapter_19.pdf)
- AIM-120, as described in the opened encyclopedia article: the aircraft passes pre-launch location, direction, and speed; the missile’s inertial system flies an intercept course; if the shooter or a surrogate keeps tracking, periodic updates of changes in direction and speed are sent and the rear fins steer the missile toward a self-homing distance where the target is inside the basket, defined there as the missile radar’s field of view. At short range the active seeker can be used just after launch. The article does not print a range or a time-to-go at which the transmitter turns on. — [AIM-120 AMRAAM, Wikipedia, guidance section, opened 2026-09-29](https://en.wikipedia.org/wiki/AIM-120_AMRAAM)
- Mid-course guidance, in the NATO lecture, guides the missile to the vicinity of the target with data from an external sensor. AMRAAM is the air-to-air example named there. — [Berglund, in RTO-EN-018 / ADA394520](https://dn720709.ca.archive.org/0/items/technologies-for-future-precision-strike-ada-394520/Technologies%20for%20Future%20Precision%20Strike%20%28ADA394520%29.pdf)
- Zero line-of-sight rate means the pair is already on a collision triangle, so proportional navigation commands nothing further. Zero-effort miss, if the target does not maneuver, is the constant-velocity prediction of future separation. The command perpendicular to the line of sight is \(n_c = N' V_c \dot\lambda = N'\,\mathrm{ZEM}_{PLOS}/t_{go}^2\), with \(V_c\) the closing speed. — [Zarchan, *Tactical and Strategic Missile Guidance* (2012), ch. 2](https://archive.org/stream/TacticalAndStrategicMissileGuidance2012/Tactical%20and%20Strategic%20Missile%20Guidance%20(2012)_djvu.txt)
- This project already treats active homing as that same command after the missile radar has locked, using the missile’s own power, gain, and wavelength, and treats the pre-lock command as the last datalink state propagated at constant target velocity. A hit is still the separation when closing speed changes sign. The physics step is 0.01 s. — [Sensor weapon and terrain physics](C:/Users/alede/Documents/code/missilesim/reports/Sensor%20weapon%20and%20terrain%20physics.md); [Application.h](C:/Users/alede/Documents/code/missilesim/src/application/Application.h)
- Rail-guided powered separation, in an opened abstract and research-gate extract, is a constrained slide on the rail followed by tip-off while the aft shoe is still on the rail. A Chinese journal abstract names guide-rail, store ejection, and embedded ejection as the mainstream air-to-air launch modes. Neither opened extract prints a fighter-pylon eject speed. — [Anandhanarayanan et al., separation-dynamics abstract](https://www.researchgate.net/publication/274433064_Separation_Dynamics_of_Air-to-Air_Missile_Using_a_Grid-Free_Euler_Solver); [CAMA / NPU launch-technology abstract, 2018](http://hkgcjz.cnjournals.com/hkgcjzen/article/abstract/2017084?st=article_issue)

### Inferences

State logic that stays inside those sentences, with motor state held separate (next section):

1. **Launch.** Initial velocity is the shooter’s. Rail: stay on the shooter’s velocity direction until a data clearance time, because the opened rail description is a constraint, not an immediate free 6-DoF body. Eject: add a data velocity in aircraft axes, then the same clearance. No universal eject speed was opened, so the default increment is zero and must be labeled unpublished. Guidance inhibit, already a Fox 2 card field, is the clearance timer.
2. **Midcourse.** Until the seeker has acquired, the line-of-sight rate that enters \(n_c = N' V_c \dot\lambda\) is not the true target. The missile integrates its own navigation state and a target state from pre-launch data, replaced when an update arrives. The steer is toward the predicted intercept (zero-effort miss at constant target velocity, or a loft command below), not toward the geometric target.
3. **Seeker search.** Turn the transmitter on only when the predicted target lies in the angle, range, and Doppler basket the seeker can search, and enough homing time remains. Skolnik’s “about ten guidance time constants” or “a few kilometres” is a scale for that remaining time, not a card constant and not an acquisition range. Acquisition range is the monostatic equation’s output. Short-range shots may enter search immediately, which is the Wikipedia AIM-120 statement and Skolnik’s homing-all-the-way case.
4. **Terminal.** After acquisition, the contact’s angle rate and closing speed drive the same proportional-navigation command. The missile no longer needs the datalink.
5. **Coast.** After the motor is out, or between pulses, drag and guidance continue. Coast does not by itself switch the seeker or the guidance law.

A fixed range that both launches the terminal phase and decides detection is the failure mode this project is removing. Skolnik states two different typical scales (ten time constants, and a few kilometres) in one chapter; they agree only for a particular closing speed and a particular \(T\).

### Gaps

- No opened page is an AMRAAM timeline, a seeker-on range, or a time-to-go table. Those were not searched in employment manuals.
- Fighter rail-exit speed increment and pylon eject velocity were not in the opened extracts. The Fox 2 note already found no rail-exit speed to add.
- Tip-off angular rate is a constrained-rail 6-DoF effect. A point-mass step cannot reproduce it without a data rate that was not published.

## Loft and energy management

### Takeaway

A long-range missile climbs because dynamic pressure, hence drag, is lower in thinner air, so the same impulse can leave more speed at the intercept. The opened air-to-air guidance law for that climb is an altitude program tracked by a lead-angle command, not proportional navigation flown from launch. Pure proportional navigation does not loft: on a collision triangle its command is zero. A loft can raise time of flight and terminal speed, but those are different optima, and an arbitrary climb does not guarantee both.

### Cited Findings

- “Air-to-air missiles often employ trajectory optimisation during the mid-course. The main reason for this is to exploit the lower drag at higher altitude. Optimisation can be used to obtain minimal time of flight, maximal range, maximal terminal velocity etc.” — [Berglund, RTO-EN-018](https://dn720709.ca.archive.org/0/items/technologies-for-future-precision-strike-ada-394520/Technologies%20for%20Future%20Precision%20Strike%20%28ADA394520%29.pdf)
- In the same volume, a separate lecture on precision-strike shaping (not an air-to-air measurement): the missile should pitch up rapidly and climb at small angle of attack to limit drag; a climb thrust-to-weight above about 2 raises dynamic pressure and drag; efficient cruise dynamic pressure for a low-aspect-ratio missile is of order 500–1000 psf, with a post-burnout glide near 700 psf. Those numbers are that lecture’s design guidelines. They are not an AMRAAM card. — [Licata, in RTO-EN-018](https://dn720709.ca.archive.org/0/items/technologies-for-future-precision-strike-ada-394520/Technologies%20for%20Future%20Precision%20Strike%20%28ADA394520%29.pdf)
- For a given predicted intercept, “the optimal trajectory that maximizes terminal speed typically takes the form of initial climb to a high altitude to minimize drag, followed by a pull-down.” At the high altitude, density is lower and the pull-down uses angle of attack, so less acceleration remains for a later change in the predicted intercept. The guidance they fly is not proportional navigation. Pursuit guidance points the velocity at the target. Augmented pursuit is \(a_{\mathrm{com}} = N V (\lambda_{\mathrm{com}} - \lambda)\), and \(\lambda_{\mathrm{com}}\) is chosen so the missile follows an altitude that is a polynomial of range-to-go. A high peak is more fragile to a moved intercept point. — [Shin, Tahk, Kim, and Lee, ICAS 2024](https://www.icas.org/icas_archive/icas2024/data/papers/icas2024_0828_paper.pdf)
- Skolnik’s up-and-over sentence is the same drag reason from the seeker side: a commanded or inertial trajectory that spends less time in denser low-altitude air reaches longer range. — [Skolnik, ch. 19](https://ww.helitavia.com/skolnik/Skolnik_chapter_19.pdf)
- Zarchan’s trajectory-shaping law is a different problem: hit, and arrive on a designer-chosen final line-of-sight angle \(\lambda_F\), while minimizing the integral of acceleration squared. The opened text reduces it to proportional navigation with effective navigation ratio 4, plus a term in \((\lambda - \lambda_F)/t_{go}\), plus a target-acceleration term. The unsimplified command he prints is \(n_c = (6y + 4 \dot y\, t_{go} + n_T t_{go}^2 + 2 \dot y(t_F) t_{go}) / t_{go}^2\). The alternate form he states is \(n_c = 4 V_c \dot\lambda + 2 V_c (\lambda - \lambda_F)/t_{go} + n_T\). It needs time-to-go and line-of-sight angle. Proportional navigation needs neither a time-to-go nor a final angle. In his examples the shaping law uses more acceleration than proportional navigation. It is not derived there as a drag or altitude program. — [Zarchan (2012), ch. 24](https://archive.org/stream/TacticalAndStrategicMissileGuidance2012/Tactical%20and%20Strategic%20Missile%20Guidance%20(2012)_djvu.txt)
- Separately, Zarchan notes that raising the flight-path angle of a ballistic trajectory increases time of flight, and that long-range ground-launched missiles are shaped upward so that drag removes less range and velocity. That sentence is about ground launch, not an air-to-air shot. — [Zarchan (2012), strategic and drag-reach discussion](https://archive.org/stream/TacticalAndStrategicMissileGuidance2012/Tactical%20and%20Strategic%20Missile%20Guidance%20(2012)_djvu.txt)
- Zero line-of-sight rate is the collision triangle and the proportional-navigation command is then zero. — [Zarchan (2012), ch. 2](https://archive.org/stream/TacticalAndStrategicMissileGuidance2012/Tactical%20and%20Strategic%20Missile%20Guidance%20(2012)_djvu.txt)
- Drag is \(D = C_D \rho V^2 A / 2\). Dynamic pressure is \(\rho V^2/2\). — [NASA Glenn, Drag Equation](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/drag-equation/)
- This project’s guidance note already uses specific energy \(h + V^2/(2g)\) and specific excess power \(V(T-D)/W\) as diagnostics, not as a second integrator. Angle-of-attack saturation at low dynamic pressure is Zarchan’s high-altitude limit, already adopted: available load factor is the minimum of structure and \(q S C_{N,\max}/m\). — [missile-guidance-propulsion.md](C:/Users/alede/Documents/code/missilesim/research_notes/Sensor%20weapon%20and%20terrain%20physics/missile-guidance-propulsion.md)
- A lofted terminal dive looks down. Skolnik: noncoherent pulse active seekers were not suitable against small aircraft in low-altitude clutter; air-defense active seekers use pulse-Doppler, and the clutter tradeoffs are the same as in an airborne intercept radar. The active seeker is monostatic. — [Skolnik, ch. 19](https://ww.helitavia.com/skolnik/Skolnik_chapter_19.pdf)

### Inferences

- Proportional navigation from launch does not implement loft. If the missile is placed on the collision triangle, \(\dot\lambda = 0\) and the command stays zero, so the path is straight in the relative frame (gravity must be removed or shared; see the validation section). A climb has to be commanded by something else: an altitude polynomial and a lead angle (ICAS), a flight-path-angle program with small angle of attack on the way up (Licata’s guideline, labeled as not an air-to-air measurement), or Zarchan’s \(\lambda_F\) term if the designer actually wants a terminal line-of-sight angle. The \(\lambda_F\) law is the opened closed-form shaping command. It spends acceleration to buy an angle. It is not the opened proof that the climb saves drag.
- Energy along the path, using the project’s specific-excess-power identity and NASA’s drag: \(\mathrm{d}E_s/\mathrm{d}t = V(T-D)/W\) with \(E_s = h + V^2/(2g)\), so the drag work per distance is \(D = q S C_D\). Climbing into lower \(\rho\) reduces \(q\) at a given speed and therefore reduces that work, which is Berglund’s reason and the ICAS speed-maximizing shape. Terminal speed is higher only if that saving exceeds the drag of the extra path and any specific energy still sitting in altitude at intercept. Descending to the same intercept altitude returns the potential, minus the drag on the way down.
- Time of flight is a different objective. Berglund lists minimum time of flight and maximum terminal velocity as separate optimisation goals. A higher ballistic flight-path angle increases time of flight in Zarchan’s closed form, but that form is not an air-to-air drag solution. A loft therefore does not automatically both take longer and arrive faster. The test in the validation section has to score them separately.
- Look-down is not a second guidance law. The loft changes the elevation the radar dwell sees. Clutter and multipath stay in the sensor report. Thin air also cuts the load factor \(q S C_N/m\), which is why ICAS caps peak altitude: the pull-down can saturate before a moved intercept is reachable. The flight card can carry a peak-altitude or minimum-dynamic-pressure limit. It should not carry a brochure ceiling.

### Gaps

- No opened air-to-air page prints the polynomial coefficients, the cruise altitude, or the dynamic-pressure band of a named Fox 3. Licata’s 500–1000 psf band is a precision-strike guideline in the same NATO volume.
- Zarchan’s simplified shaping command is what the opened OCR states, including a target term \(+ n_T\) rather than \(N' n_T/2\). The algebra between the two printed forms was not re-derived here.
- Wikipedia’s lofting page gives peak altitudes of about 24–30 km for “most” air-to-air missiles. Those figures trace to a blog and to a reading of the ICAS paper that this pass did not confirm in the PDF extract, so they are not used.

## Datalink and the coast error

### Takeaway

The opened air-to-air message is a target state, not a fin command: location, direction, and speed before launch, then updates of direction and speed. Between updates the missile coasts that state at constant velocity. If the target in fact has a constant acceleration that was not in the message, Zarchan’s predicted-miss term says the position error grows as \(\tfrac{1}{2} n_T \tau^2\), where \(\tau\) is the age of the update. That identification is the kinematics he prints, applied to the update age.

### Cited Findings

- Pre-launch, the aircraft gives location, direction, and speed, from its radar or from another fighter, an infrared search track, or an AWACS. After launch, periodic updates “e.g. changes in the target’s direction and speed” let the missile correct with its fins so the target falls in the seeker field of view. Without the mid-course update, the article says trials found the AIM-120 less effective in beyond-visual-range shots than semi-active Skyflash, because the missile’s own radar has less range and power than the launch aircraft’s. Not every user bought the update. — [AIM-120 AMRAAM, Wikipedia](https://en.wikipedia.org/wiki/AIM-120_AMRAAM)
- Meteor, as opened on the same day: inertial guidance, mid-course datalink, terminal active radar. The two-way link carries target updates or retargeting, including from a third party, and the missile can send kinematic status and a notice that the seeker has acquired. — [Meteor, Wikipedia](https://en.wikipedia.org/wiki/Meteor_(missile))
- Skolnik’s midcourse initialization is angle (antenna pointing) and range and/or Doppler, from pre-launch data or command updates. He also describes a different architecture, command guidance, in which the missile does not perceive the target and the uplink is a steering command. Sampled illumination can be a midcourse mode for an active terminal seeker; midcourse can run at a lower data rate than terminal homing. — [Skolnik, ch. 19](https://ww.helitavia.com/skolnik/Skolnik_chapter_19.pdf)
- Zarchan defines zero-effort miss, when the target does not maneuver, as the constant-velocity prediction of future separation. With a constant target acceleration, the predicted position at intercept gains the term he writes \(0.5\, n_T (t_F - t)^2\). The optimal zero-lag command that minimizes \(\int n_c^2\) is \(n_c = 3(y + \dot y\, t_{go} + 0.5\, n_T t_{go}^2)/t_{go}^2\). Augmented proportional navigation is \(n_{c,\mathrm{APN}} = N' V_c \dot\lambda + 0.5 N' n_T\), and he states that it assumes the target acceleration can be estimated. — [Zarchan (2012), ch. 2 and ch. 8](https://archive.org/stream/TacticalAndStrategicMissileGuidance2012/Tactical%20and%20Strategic%20Missile%20Guidance%20(2012)_djvu.txt)
- This project’s weapon packet is a time, a range, a range rate, two angles, four sigmas, and a coast flag, plus either an illumination window or discrete datalink states. It is the interface the flight model must consume. It is not an AIM-120 message format. — [Sensor weapon and terrain physics](C:/Users/alede/Documents/code/missilesim/reports/Sensor%20weapon%20and%20terrain%20physics.md)

### Inferences

- Two uplinks must not be mixed. The air-to-air descriptions send the target’s kinematic state and let the missile steer. Skolnik’s command-guidance uplink sends acceleration commands and does not belong on a fire-and-forget Fox 3. Ship midcourse that flies the missile to a predicted intercept point is the command case.
- Between messages, integrate the last target position with the last target velocity and with acceleration zero, unless that message actually carried an acceleration. The missile’s own state keeps integrating accelerometers, or in this point-mass sim, the forces it already applies. A stale target state is Zarchan’s constant-velocity zero-effort miss.
- The coast error is his missing term. If the true target acceleration perpendicular to the predicted line of sight is a constant \(n_T\) that the message did not contain, the position error after age \(\tau\) is \(\tfrac{1}{2} n_T \tau^2\). That is the \(0.5\, n_T (t_F-t)^2\) term with the time interval equal to the age of the update, not equal to time-to-go. It is an inference from the equation he prints, not a sentence in an AIM-120 interface control document. Augmented proportional navigation may add \(0.5 N' n_T\) only when the message or a filter actually estimates \(n_T\). A direction-and-speed update, as Wikipedia describes it, does not.
- The basket grows with that error, with navigation drift, and with the angle uncertainty of the last track. When the angular error exceeds the field the seeker will search, acquisition fails even if a hard-coded range says the missile is “close enough.” That is the blackout test below.
- Message rate is data. Skolnik only says midcourse may be slower than terminal. No Hertz value was opened.

### Gaps

- A Korean open-access note turned up in search as saying the uplink carries position, velocity, and an accuracy. The PDF was not opened, so those three words are not used as a finding.
- Covariance, message period, and whether acceleration is included were not in the opened AIM-120 or Meteor descriptions. The project packet’s sigmas are the place to put accuracy once a source for them exists. Until then the sigmas are an empty input, not a guessed AMRAAM variance.
- One-way versus two-way is described for Meteor (two-way, including an acquisition notice). The AIM-120 article describes updates to the missile and does not describe a downlink. A downlink of seeker status must be a card flag, not assumed for every Fox 3.

## Active seeker against a Fox 2 seeker, with Fox 1 in one pass

### Takeaway

After lock, the guidance law does not care that the angle came from a monopulse radar instead of an infrared centroid. What changes is the measurement: the Fox 3 seeker is a small monostatic pulse-Doppler radar with its own power, gain, frequency, and beam, short-ranged relative to the launch aircraft, and it is off or only searching until handover. Home-on-jam is a passive angle track used when the skin return cannot be tracked, and skin track is preferred again when it can. Fox 1 is the opposite support condition: an external illuminator and a rear reference for the whole homing interval.

### Cited Findings

- The active seeker carries its own illuminator and drops the semi-active rear receiver. The reference is a sample of the missile’s own exciter. A single antenna cannot isolate a continuous-wave transmitter from the receiver, so the active waveform is noncoherent pulse or coherent pulse-Doppler. For air targets the usual choice is pulse-Doppler, because a noncoherent pulse could not handle small aircraft in clutter. The active set is a miniature fire-control radar and is monostatic; semi-active is bistatic. Angle tracking has been conical scan or monopulse. Range is “considerably less” than a large-illuminator semi-active seeker. — [Skolnik, ch. 19](https://ww.helitavia.com/skolnik/Skolnik_chapter_19.pdf)
- Home-on-jam is one of three passive modes he names (with anti-radiation and radiometric), and “an essential adjunct for semiactive and active systems to counter noise jamming.” Wideband noise can mask the skin echo, but the jammer is then a point source of angle. “When the jamming is such that tracking of the target skin return is not possible, the seeker switches to passive tracking of the received jamming energy. If the jammer-to-signal ratio (\(J/S\)) decreases to the point that skin track is again possible, this is given preference over HOJ.” Intermittent jamming must be able to switch either way. He does not print a numeric \(J/S\) threshold. The criterion he states is which mode gives the better guidance information. — [Skolnik, ch. 19](https://ww.helitavia.com/skolnik/Skolnik_chapter_19.pdf)
- The AIM-120 article says the missile can switch from active homing to passive homing on the target’s jamming when onboard software decides it is being jammed. That paragraph, as opened, has no footnote and no threshold. It is not used as the condition. The condition above is Skolnik’s. — [AIM-120 AMRAAM, Wikipedia](https://en.wikipedia.org/wiki/AIM-120_AMRAAM)
- The same article’s semi-active contrast, written there about Sparrow: the fighter must illuminate the target, only one target was illuminated at a time, and the fighter had to keep the target inside its own radar’s angle limits. The missile homes on the reflection. — [AIM-120 AMRAAM, Wikipedia](https://en.wikipedia.org/wiki/AIM-120_AMRAAM)
- This project already recorded the semi-active conditions and the one closed form that was printed: semi-active homing is valid only while the illuminator beam contains the target and the missile has a coherent rear reference; continuous-wave semi-active does not itself measure range; for a stationary illuminator and a head-on collision, \(f_d = (f_0/c)\, 2 V_c\). Active homing uses the monostatic equation with the missile’s power, gain, and wavelength, and proportional navigation starts after lock. Emitter records hold peak power, gains, frequency, pulse width, PRF, beamwidths, noise figure or system temperature, losses, false-alarm probability, and integration type. They do not hold a lock range. — [Sensor weapon and terrain physics](C:/Users/alede/Documents/code/missilesim/reports/Sensor%20weapon%20and%20terrain%20physics.md); [Skolnik, ch. 19](https://ww.helitavia.com/skolnik/Skolnik_chapter_19.pdf)
- A Fox 2 seeker, in this sim, outputs an angle from irradiance. It has an instantaneous field, a gimbal, and a track rate. It does not measure range or Doppler. Lock-after-launch slews to a cue and then searches. The guidance law adopted for either angle source is \(n_c = N' V_c \dot\lambda\). — [Fox2Catalog.h](C:/Users/alede/Documents/code/missilesim/src/sim/Fox2Catalog.h); [Sensor weapon and terrain physics](C:/Users/alede/Documents/code/missilesim/reports/Sensor%20weapon%20and%20terrain%20physics.md)

### Inferences

- The Fox 3 card points at an emitter record. It does not grow a `tailAcquisitionM`. Power, gain, frequency, beamwidth, and noise floor enter the radar equation the sensor report already specified. Field of view and field of regard are the search basket and the gimbal stop, same geometry as the infrared seeker, different physics inside the basket.
- Until the contact exists, there is no \(\dot\lambda\) from the target. Steering uses the propagated state. A truth line of sight in that interval is a debug sensor, and it has to be labeled as one.
- Home-on-jam, if implemented, is a change of angle source, not of guidance law: when the dwell says the skin track is impossible and a jammer angle exists, \(\dot\lambda\) comes from that angle; when skin track returns, it replaces the jammer. No \(J/S\) number is invented here. The sensor report’s jamming stage is what decides “skin not possible.”
- Fox 1, one contrast: the missile has no transmitter, the Doppler reference is a rear sample of the fighter’s illumination, and homing dies when the beam or the reference dies. Fox 3’s transmitter is on the missile, so after lock the shooter can leave. Before lock, Fox 3 still depends on the datalink in the same way Fox 1 depends on the illuminator.

### Gaps

- Seeker frequency, power, gain, and beamwidth of any named Fox 3 were not opened. They stay empty emitter fields.
- The numeric \(J/S\) at which skin track is “not possible” was not in the Skolnik section that was opened.
- Radome aberration and glint are sensor errors on \(\dot\lambda\). They are already in the sensor report’s angle stage and are not restated.

## Propulsion states the card must carry

### Takeaway

Four motor classes use the same force law and different state. Boost-coast and boost-sustain are one ignition and a thrust table. Dual-pulse is two ignitions and a predicate for the second. A throttleable ducted rocket is a booster, then a valve-controlled gas generator whose thrust also depends on captured air. None of these is a grain design, and none is a range.

### Cited Findings

- Thrust in this sim already rises as ambient pressure falls, through the nozzle pressure term. Specific impulse converts a constant-thrust segment into mass flow by \(I_{sp} = F/(\dot m g_0)\). A thrust-versus-time table is the motor when the curve exists. A rectangular spread of impulse over burn time is the fallback when only an impulse and a duration were printed. Coast uses the full base drag; powered flight uses the reduced base. — [Sensor weapon and terrain physics](C:/Users/alede/Documents/code/missilesim/reports/Sensor%20weapon%20and%20terrain%20physics.md); [Fox2Flight.h](C:/Users/alede/Documents/code/missilesim/src/sim/Fox2Flight.h)
- The AIM-120 encyclopedia infobox says A/B and C-1 through C-4 are a boost-sustainer, and C-5 and later, including D, are “booster only.” The infobox points at Jane’s. Jane’s was not opened. The sentence is not a thrust curve and is not copied onto a card as newtons. — [AIM-120 AMRAAM, Wikipedia](https://en.wikipedia.org/wiki/AIM-120_AMRAAM)
- A dual-pulse solid motor, in the opened patent, burns twice in one stage. The method claimed there conserves the second burn until onboard sensors acquire the target, then ignites it as the vehicle turns onto the homing heading. The patent defines target acquisition as location of the target by the vehicle’s own sensors, and homing as what follows. It also says dual-pulse motors have been used to improve range and end speed. It does not give a thrust split. — [US20040124306A1](https://patents.google.com/patent/US20040124306A1/en)
- A dual-pulse solid rocket motor, in an opened journal abstract, burns two propellant charges in chambers separated by a pulse-separation device, exhausts both through one nozzle, and can choose the delay between first-pulse burnout and second-pulse ignition. The abstract is about ignition transients, not a flight thrust table. — [Li, Wang, and others, *Acta Astronautica*, 2018, abstract](https://www.sciencedirect.com/science/article/abs/pii/S0094576517309864)
- Meteor’s propulsion, as opened: a throttleable ducted rocket with an integrated nozzleless booster. Intakes and port covers stay closed during boost. The booster accelerates the missile to a speed at which the ducted rocket can take over. The gas generator is lit by booster gas through the open control valve and burns an oxygen-deficient solid. Thrust is controlled by a valve that changes the gas-generator throat area: a smaller throat raises generator pressure, raises burn rate, and raises fuel mass flow. The page says the mass flow can be varied continuously over a ratio greater than 10:1. Fins are four, at the tail, and the control layout is described as keeping the intakes fed while the missile turns. A two-way datalink and terminal active radar are the guidance, not the motor. The page’s “roughly threefold” specific impulse versus a solid rocket, and the no-escape-zone multiples, are manufacturer claims printed there. They are not a sim impulse. — [Meteor, Wikipedia](https://en.wikipedia.org/wiki/Meteor_(missile))
- Raytheon’s UK bid, in that same article, included an interim missile with a dual-pulse solid motor as a step short of a ramjet. That is a historical proposal, not a thrust table. — [Meteor, Wikipedia](https://en.wikipedia.org/wiki/Meteor_(missile))

### Inferences

Motor state is orthogonal to guidance phase, except where a card predicate couples them. The patent’s “second burn at acquisition” is one legal predicate. It is not the default for every dual-pulse round.

- **Boost-coast.** States: `burning`, time since ignition, propellant mass, and a thrust table or one rectangular segment. When time exceeds the burn, or propellant mass hits zero, thrust is zero and base drag is the coast value. One ignition.
- **Boost-sustain.** The same states. The table has a high segment and a low segment and no zero between them. There is no second igniter. Inventing the split when only a total impulse was published repeats the Fox 2 rule this project already refused.
- **Dual-pulse.** States: pulse index, time in the current pulse, interpulse coast time, propellant mass of the pulse now burning, and an ignition predicate for pulse two. Predicate inputs that the opened sources actually support: a time delay (the journal says the delay is controllable) or onboard acquisition (the patent). Range, dynamic pressure, and time-to-go are not published triggers and must be labeled if a card uses them. During the interpulse gap, thrust is zero and the guidance phase does not change unless the predicate says so.
- **Throttleable ducted rocket.** States: `boost` (intakes closed, nozzleless booster, thrust table plus the pressure term), `transition` (booster spent and speed at or above a data takeover Mach, intakes open), `sustain` (valve command, gas-generator propellant mass, fuel mass flow), `coast` (fuel gone). On sustain, thrust is not a vacuum table. It depends on captured airflow, so on Mach and altitude, and on the valve. The opened description supports a commanded mass-flow or a commanded speed whose actuator is throat area. It does not support a solid-rocket \(I_{sp}\) applied to the ramjet plume. The 10:1 flow ratio is a limit on the valve, not a thrust-versus-time curve. Minimum takeover Mach is data and was not numeric in the opened page.

Mass flow on a rocket segment stays \(F/(I_{sp} g_0)\) only while that segment’s \(I_{sp}\) is meaningful. A ducted rocket’s specific impulse is a different definition (fuel only, air from outside) and must not reuse the solid-rocket converter.

### Gaps

- No opened source gives a Fox 3 thrust-time pair, a pulse split, a takeover Mach, or a valve schedule. The Wikipedia boost-sustain label was not checked against Jane’s.
- The DTIC note on Mach control of a ducted-rocket gas generator was not re-opened (maintenance page). The valve law used above is the Meteor article, not that report.
- Grain geometry, burn-rate exponents, and boron loading are propulsion interior ballistics. They were seen in search hits and are intentionally not specified.

## Endgame: what Fox 3 adds, and what it must not override

### Takeaway

Terminal guidance is the law the sensor report already adopted: \(n_c = N' V_c \dot\lambda\), perpendicular to the line of sight, through one lag, then the load-factor limit. Miss is the separation when closing speed changes sign. Fox 3 adds a radar contact in place of an infrared centroid, and a Doppler closing speed when that contact exists. It must not replace the command, the miss test, or the fuze with a sphere or a stored range.

### Cited Findings

- Zarchan’s command is \(n_c = N' V_c \dot\lambda\), \(N'\) usually 3 to 5, \(V_c\) the negative of range rate. Miss distance is the separation at the sign change of closing velocity. Augmented proportional navigation adds \(0.5 N' n_T\) only when target acceleration is estimated. A single guidance lag is the model he adjoints; his plots use a 1 s time constant because they are normalized. — [Zarchan (2012)](https://archive.org/stream/TacticalAndStrategicMissileGuidance2012/Tactical%20and%20Strategic%20Missile%20Guidance%20(2012)_djvu.txt)
- The sensor report adopts that command and that miss test for a reticle, a focal plane, or a monopulse radar. The Fox 2 code instead commands \(N\) times missile speed, perpendicular to velocity, with \(N\) clamped to 3–5, and blends a heading-error turn. The report says the missile-speed law is not the one Zarchan linearizes, and that achieved acceleration is applied in the same tick with no autopilot state. The smallest model of the adjoint is \(\dot n = (n_c - n)/T\). The fuze is not the seeker and not the proximity sphere. — [Sensor weapon and terrain physics](C:/Users/alede/Documents/code/missilesim/reports/Sensor%20weapon%20and%20terrain%20physics.md); [missile-guidance-propulsion.md](C:/Users/alede/Documents/code/missilesim/research_notes/Sensor%20weapon%20and%20terrain%20physics/missile-guidance-propulsion.md)
- After acquisition, Skolnik says seeker operation proceeds as in the semi-active case until intercept. The angle, not a separate endgame law, is what homing consumes. — [Skolnik, ch. 19](https://ww.helitavia.com/skolnik/Skolnik_chapter_19.pdf)
- The acceptance table’s seeker row is: \(\dot\lambda\) from the contact or the irradiance centroid, then \(n_c = N' V_c \dot\lambda\) through a first-order lag and the load-factor limit. The closed-form gate is that \(\dot\lambda = 0\) commands zero acceleration, and miss is recorded when \(V_c\) changes sign. Zones are the same integrator, and a stored kilometre is what that row leaves blank. — [Sensor weapon and terrain physics](C:/Users/alede/Documents/code/missilesim/reports/Sensor%20weapon%20and%20terrain%20physics.md)

### Inferences

- Fox 3’s addition is the source of \(\dot\lambda\) and of \(V_c\). A locked radar contact supplies both (angle from monopulse, closing speed from Doppler). An infrared centroid supplies an angle, and closing speed is geometric only if something else measures range. While two radar returns are unresolved, the angle is whatever single track the seeker outputs; the command does not grow a second term.
- What Fox 3 must not override: the \(V_c\) form of the command, the lag, the load-factor limit \(\min(n_{\mathrm{struct}}, qSC_{N,\max}/m)\), the miss-at-sign-change test, and the rule that the fuze is a separate beam and lethal radius. The Fox 2 \(N V_m\) law and its heading-error blend stay on Fox 2. Putting them on the active terminal phase would make the acceptance gate \(\dot\lambda = 0 \Rightarrow n_c = 0\) ambiguous whenever \(V_c\) and \(V_m\) differ.
- Midcourse loft and datalink pursuit are not the endgame. They stop at acquisition. A residual heading error at handover is Zarchan’s heading-error problem on the remaining time-to-go. If that time is only a few guidance time constants, Skolnik’s “ten time constants” is the warning that the lag will not finish the correction. The sim integrates the lag; it does not add a canned miss.

### Gaps

- No opened Fox 3 page prints \(N'\) or the autopilot time constant. \(N'\) stays in 3–5. \(T\) stays a card field. The AIM-9B 0.25 s value is that round’s, already in the sensor report, and is not copied onto a radar missile.
- Warhead lethal radius and fuze beam were left blank in the sensor report and are still blank.

## Validation cases

### Takeaway

Three checks have closed forms that do not need a brochure range: a collision triangle commands nothing and misses nothing; a loft is scored by time of flight and by drag work, not by one number that must rise; a datalink blackout moves the target by \(\tfrac{1}{2} n_T \tau^2\) and can walk it out of the seeker basket.

### Cited Findings

- Zero line-of-sight rate is a collision triangle, and the command is zero. Constant-velocity zero-effort miss is \(y + \dot y\, t_{go}\). If that perpendicular miss is zero, the command is zero. Miss is the separation when closing velocity changes sign. — [Zarchan (2012), ch. 2](https://archive.org/stream/TacticalAndStrategicMissileGuidance2012/Tactical%20and%20Strategic%20Missile%20Guidance%20(2012)_djvu.txt)
- The acceptance table already gates \(\dot\lambda = 0\) to zero acceleration, and gates a zone on the integrator rather than on a stored kilometre. — [Sensor weapon and terrain physics](C:/Users/alede/Documents/code/missilesim/reports/Sensor%20weapon%20and%20terrain%20physics.md)
- Maximum terminal speed, in the opened air-to-air midcourse paper, is a climb and a pull-down. Minimum time of flight is a different objective from maximum terminal velocity. Raising flight-path angle increases time of flight in Zarchan’s ballistic closed form. Drag work is \(D = q S C_D\) with \(q = \rho V^2/2\). — [Shin et al., ICAS 2024](https://www.icas.org/icas_archive/icas2024/data/papers/icas2024_0828_paper.pdf); [Berglund, RTO-EN-018](https://dn720709.ca.archive.org/0/items/technologies-for-future-precision-strike-ada-394520/Technologies%20for%20Future%20Precision%20Strike%20%28ADA394520%29.pdf); [Zarchan (2012)](https://archive.org/stream/TacticalAndStrategicMissileGuidance2012/Tactical%20and%20Strategic%20Missile%20Guidance%20(2012)_djvu.txt); [NASA Glenn](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/drag-equation/)
- The position contribution of a constant target acceleration over an interval \(\tau\) is \(0.5 n_T \tau^2\), which is the term in Zarchan’s predicted intercept. — [Zarchan (2012), ch. 8](https://archive.org/stream/TacticalAndStrategicMissileGuidance2012/Tactical%20and%20Strategic%20Missile%20Guidance%20(2012)_djvu.txt)
- The seeker searches an uncertainty set in angle and in range or Doppler, then acquires. Terminal range is the region in which that search can succeed, not a stored kilometre. — [Skolnik, ch. 19](https://ww.helitavia.com/skolnik/Skolnik_chapter_19.pdf)

### Inferences

1. **Collision triangle.** Place a constant-velocity target and a missile whose velocity already satisfies \(\dot\lambda = 0\). Turn gravity off, or give both the same vertical acceleration so the relative acceleration is zero. With \(N'\) in the usual band and no lag error, the command is zero for the whole flight and the miss at the sign change of \(V_c\) is zero, to integrator tolerance. This is the acceptance-table gate. It does not need a seeker model if \(\dot\lambda\) is taken from truth for this test only.
2. **Loft versus that straight path.** Same motor, same end altitude. Fly the straight collision case, and fly an altitude polynomial that climbs and returns to the same altitude. Record time of flight and \(\int D\,\mathrm{d}s = \int q S C_D\,\mathrm{d}s\). Specific energy at intercept differs from the straight shot by the difference in drag work, because thrust impulse and the potential are then the same (the pressure term on thrust depends on the altitude history, so the impulse is only the same if that term is included in the integral). Terminal speed is higher on the loft only when drag work is smaller by enough to offset a lower impulse if the motor burned at a different ambient pressure. Time of flight is not required to increase. Berglund treats a short flight and a fast arrival as different problems. Zarchan’s ballistic result says a higher flight-path angle takes longer when speed is the launch speed of a coasting arc; an air-breathing or sustaining motor can break that if it is faster on the long path. The test fails if the code reports a longer flight and a higher terminal speed for every climb, or if it reports them from a stored range.
3. **Datalink blackout.** One update, then silence. Target acceleration perpendicular to the predicted line of sight is a constant \(n_T\). At age \(\tau\) the lateral position error is \(\tfrac{1}{2} n_T \tau^2\). At the moment the seeker is allowed to search, the look angle of that error is \(\mathrm{atan2}(\tfrac{1}{2} n_T \tau^2, R)\) relative to the predicted line of sight. If that angle is outside the search field, the contact is not formed and the missile continues on the stale prediction. The miss against the true target is then the zero-effort miss of the stale state, not zero. This test uses the angle basket only. It must still fail the same way after the radar equation exists, if the signal-to-noise ratio would have been enough on the true target but the seeker never looked there.

### Gaps

- No opened source gives a numerical miss for a lofted Fox 3 against a maneuver. The three checks are identities, not a range table.
- The drag-work comparison assumes the same \(C_D\) model the integrator is already using. It is not a new aerodynamic fit.

## Implementation notes for missilesim

### Takeaway

Add a guidance phase and a motor phase beside the Fox 2 card. Terminal homing consumes a radar contact and the command the sensor report already fixed. Seeker turn-on is that contact’s existence inside a basket, not a new kilometre. Build the kinematic tests before the radar stages, and do not let a Fox 3 path reach the zone row with a stored range.

### Cited Findings

- Fox 2 `Spec` already carries mass, length, diameter, span, one thrust, one burn time, propellant mass, motor confidence, structural and coast \(g\), a normal-force coefficient, instantaneous field, gimbal, cue, track rate, lock-before or lock-after launch, guidance inhibit, guidance time limit, self-destruct, arm distance, and proximity. Infrared aspect, flare rejection, and tail-acquisition metres are Fox 2 fields. — [Fox2Catalog.h](C:/Users/alede/Documents/code/missilesim/src/sim/Fox2Catalog.h)
- The flight step is 0.01 s. Thrust has a pressure term. Drag is dynamic pressure times a Mach-dependent coefficient, with induced drag when the guidance law demands a normal force. — [Application.h](C:/Users/alede/Documents/code/missilesim/src/application/Application.h); [Fox2Flight.h](C:/Users/alede/Documents/code/missilesim/src/sim/Fox2Flight.h)
- The acceptance order is contact types, free-space radar equation, body-frame radar cross section, dwell and Swerling, propagation and clutter, angle and glint, jamming, chaff and infrared, seeker consumption of \(\dot\lambda\), then zones. A later stage must leave the earlier expected number alone. \(P_d\) may be a temporary threshold only while it is labeled temporary. Zones must not contain a stored kilometre. — [Sensor weapon and terrain physics](C:/Users/alede/Documents/code/missilesim/reports/Sensor%20weapon%20and%20terrain%20physics.md)

### Inferences

**Phases.** Keep two enumerations.

Guidance: `Launch`, `Midcourse`, `Search`, `Terminal`, `HomeOnJam`, `Memory`. `Launch` lasts for the inhibit or the rail-clearance time. `Midcourse` steers on the propagated target state and, if the card says so, a loft command. `Search` starts when the handover predicate is true and ends when a contact locks or the search timer expires. `Terminal` is \(n_c = N' V_c \dot\lambda\) from that contact. `HomeOnJam` is the same command from the jammer angle, and only while the dwell says skin track is impossible. `Memory` is the stale state after the link and the seeker have both failed; it does not sample the true line of sight. A self-destruct time, if the card has one, ends `Memory`. It is not a kill.

Motor: `BoostCoast`, `BoostSustain`, `DualPulse`, or `DuctedRocket`, each with the states in the propulsion section. A dual-pulse card may name `OnAcquisition` as the second-burn predicate. Any other predicate is labeled unpublished.

**Handover predicate.** Predicted target inside the gimbal and inside the beam the seeker will scan, and inside the range-Doppler gate the emitter can form. Remaining time at least a data multiple of the guidance time constant, defaulting to Skolnik’s ten only as a labeled typical scale, not as a detection. The range test is the radar equation’s signal-to-noise ratio once that stage exists. Before that stage, a temporary threshold is allowed only with the acceptance table’s label, and it is not a lock range stored on the card.

**Loft command, chosen and named.** Default midcourse loft is an altitude polynomial of predicted range-to-go, tracked by a lead angle, because that is the opened air-to-air law (ICAS), switched off at `Search`. Zarchan’s \(4 V_c \dot\lambda + 2 V_c(\lambda-\lambda_F)/t_{go}\) is a separate card option when the requirement is a terminal line-of-sight angle. Pure proportional navigation for the whole flight is the third option and is the collision-triangle test. Do not blend them in one tick.

**Datalink.** On a message, replace target position, velocity, and the packet time. If the packet has no acceleration, propagate with \(\mathbf{a} = 0\). Age \(\tau\) is `now - packet.time`. The coast miss contribution to test against is \(\tfrac{1}{2} \mathbf{n}_T \tau^2\). Do not feed the true target into midcourse when the packet’s coast flag is set.

**Card fields beyond the Fox 2 card.** Motor class and, for dual-pulse, the second-burn predicate and the two thrust segments if they were published. For the ducted rocket, takeover Mach, intake-open flag, valve limit (the opened ratio is greater than 10:1 as a class limit, not a schedule), and gas-generator propellant mass. Launch mode `Rail` or `Eject`, plus an eject velocity that defaults to zero and is labeled unpublished. Loft mode and the altitude-polynomial coefficients or \(\lambda_F\). Datalink period and a flag for whether acceleration is in the message. Guidance time constant \(T\) and \(N'\). An emitter id for power, gain, frequency, and beam, plus gimbal and field of view. No tail-acquisition metres, no infrared aspect, no flare class.

**Order against the acceptance table.**

1. Before any radar stage: the phase machine, the motor state, and the three validation cases, using a truth angle that is compiled out of midcourse. The collision-triangle gate must already match the seeker row’s \(\dot\lambda = 0\) result, so that row does not have to be rewritten when Fox 3 arrives.
2. With the free-space radar equation: replace the temporary handover threshold with signal-to-noise ratio. Doubling range still drops power by 12.04 dB. The flight phase must not cache a range at which that was true.
3. With propagation and clutter: a lofted look-down uses the same dwell. Do not special-case a Fox 3 detection.
4. With the seeker-consumption row: terminal Fox 3 calls that command and that lag. It does not add a Fox 2 heading blend.
5. Home-on-jam waits for the jamming row, because that row is what makes “skin track impossible” a number. Until then the mode exists and stays unused.
6. Zones last, swept with the same integrator, still with no stored kilometre.

### Gaps

- Eject speed, pulse split, takeover Mach, \(N'\), \(T\), and seeker radio parameters are empty on purpose.
- This note does not implement the machine. It only fixes the states and the order.
